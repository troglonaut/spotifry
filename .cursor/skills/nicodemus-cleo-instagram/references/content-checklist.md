# Content Quality Scorecard

Use before finalizing any Nicodemus & Cleo caption, Reel plan, or post recommendation.

Score each item: **Pass / Fix / N/A**. Do not greenlight content with any critical **Fix** remaining.

## Critical (must pass)

| # | Check | Pass looks like |
|---|--------|-----------------|
| 1 | Format fit | Motion → Reel; still story → carousel; ephemeral → Story |
| 2 | Hook | First frame is payoff/action/ears/text, not setup |
| 3 | Length | Reel 7–15s (max ~20s); one clear beat |
| 4 | Mute-friendly | On-screen text carries the idea |
| 5 | Brand visible | Names and/or Highlander cues present |
| 6 | Personality accuracy | Matches real Nico/Cleo traits |
| 7 | Thumbnail | Bright, faces/ears readable |
| 8 | No duplicate upload | Same video not both carousel + separate Reel |

## Engagement (should pass often)

| # | Check | Pass looks like |
|---|--------|-----------------|
| 9 | Comment bait | Specific question tied to the clip |
| 10 | Keyword SEO | Highlander / siblings / names in first lines |
| 11 | Hashtags | 5 relevant tags, not spam |
| 12 | CTA | Soft follow/grow CTA when natural |
| 13 | Sound choice | Original audio if clicks/meows matter; otherwise soft cute audio |

## Production quality

| # | Check | Pass looks like |
|---|--------|-----------------|
| 14 | Lighting | Natural/bright; eyes catch light |
| 15 | Stability | Watchable phone footage; no nauseating shake |
| 16 | Trim | Dead time removed from start/end |
| 17 | Labels | Who’s who on 1–2 slides if first-time viewers need it |
| 18 | Series fit | Can label as Bird TV / Ear Tax / Sibling Court / etc. |

## Posting ops

| # | Check | Pass looks like |
|---|--------|-----------------|
| 19 | Timing | Prefer audience evening window or Insights peak |
| 20 | First hour | User can reply to comments + share Reel to Story |
| 21 | Cadence | Supports 4–5 Reels/week + 1–2 posts without burnout |

## Quick reject list

- “Cute cats” with no names
- Reel longer than ~25s for cold traffic
- Fake dramatic personas user didn’t approve
- Music drowning a sound-on moment
- Hashtag walls (20–30 tags)
- Posting only stills when the asset is clearly a Reel moment

## Output template for the agent

When reviewing or creating a post, end with:

```
Format: [Reel / Carousel / Story]
Hook: […]
On-screen text: […]
Caption: […]
Hashtags: [5]
Quality fixes before posting: [bullets or “none”]
```
