# Nicodemus & Cleo — Popularity Journey

Guide the user phase by phase. Always identify the current phase from their metrics/posts, then give the next actions for **that** phase only (plus a preview of the next milestone). Do not dump the whole roadmap unless they ask for the full map.

## North star

Build a recognizable Highlander sibling brand people follow for Nicodemus & Cleo specifically — then monetize without killing trust.

**Order of operations:** Quality content → reach → engaged followers → offers (affiliates → brand deals → products).

---

## Phase 0 — Foundation (0–100 followers)

**You are here if:** brand-new, views often under ~300, few/no comments.

### Goals
- Make the profile look intentional
- Teach Instagram who the account is for (Highlander / kittens / sibling cats)
- Ship enough short Reels for the algorithm to test

### Done when
- [ ] Bio + Name field set (`Nicodemus & Cleo | Highlander Cats`)
- [ ] Profile photo shows both cats / clear faces + ears
- [ ] Highlights started: Meet us / Zoomies / Cuddles / Bird TV
- [ ] 10+ Reels posted (mostly 7–15s)
- [ ] At least one pinned “Meet us” or best Reel
- [ ] Daily niche engagement habit started (10–15 real comments)

### Weekly cadence
- 4–5 Reels
- 1–2 carousels
- Stories most days
- 10–15 niche comments/day, 5–10 relevant follows/day (no follow/unfollow spam)

### Content focus
- Ear Tax / “what breed?”
- Sibling sparring
- Sound-on Bird TV
- Soft cuddles for balance

### Coaching prompts to use
- “Trim this to under 12s and put the action in frame 1.”
- “Add a comment question.”
- “Share to Story and reply for 30 minutes.”

### Avoid
- Long 30–60s Reels
- Posting only photos
- Obsessing over follower count day-to-day

## Phase 1 — First traction (100–1K followers)

**Signals:** some Reels hit 500–5K+ views; comments start; follower count moves weekly.

### Goals
- Double down on winning formats
- Turn viewers into followers with clear profile promise
- Build recognition (names + ears)

### Done when
- [ ] 2–3 content series feel familiar (Bird TV, Sibling Court, Ear Tax)
- [ ] Average Reel views trending up vs Phase 0
- [ ] Comments regularly > 0; reply rate ~100%
- [ ] Insights checked for Best time / Top content
- [ ] Collaboration attempts with similar-size kitten/Highlander accounts

### Weekly cadence
- 5–6 Reels (repeat winners with new twists)
- 1–2 carousels (milestones, meet refresh)
- Stories daily + polls (“Nico or Cleo?”)

### Content focus
- Remakes of top hooks
- Breed education shorts
- Stronger CTAs: “Follow to watch them grow”
- Occasional duet-style collab / tag exchanges with peers

### Monetization
- Optional: soft Amazon/pet affiliate in bio later in this phase (only if it fits)
- Still prioritize growth over selling

### Coaching focus
- Analyze which Reel outperformed and why (hook, length, audio, question)
- Build a “repeat this” list of 5 hooks

## Phase 2 — Momentum (1K–10K followers)

**Signals:** consistent 1K–20K views; shares/saves appear; strangers comment breed guesses.

### Goals
- Become “the Highlander sibling account” in people’s minds
- Stabilize posting system so it doesn’t burn out
- Prepare a simple media kit

### Done when
- [ ] Recognizable series + visual style
- [ ] Email for collabs in bio or link hub
- [ ] Highlight covers look branded
- [ ] 1–2 small brand freebies or affiliate conversions tested
- [ ] Media kit one-pager drafted (followers, engagement, niche, sample posts)

### Weekly cadence
- 4–6 Reels (quality maintained)
- 1 carousel
- Stories daily
- 2–3 community replies/collab outreaches/week

### Content focus
- Growth diary (size comparisons, new skills)
- Higher production still OK if authentic
- Fan engagement: stitch comments, “you asked…” replies

### Monetization
- Affiliates: litter, food, toys, trees, tunnels
- Gifted product seeding with micro pet brands
- Track what audience asks for

---

## Phase 3 — Popular micro (10K–50K followers)

**Signals:** brands DM; Reels often 10K+; loyal commenters.

### Goals
- Convert attention into income without selling out
- Keep authenticity (real personalities)
- Expand lightly (TikTok/YouTube Shorts cross-post if capacity)

### Done when
- [ ] Rate card / package basics ready
- [ ] 1+ paid or product-for-post collab completed cleanly
- [ ] Content calendar running 2–4 weeks ahead
- [ ] Audience trusts recommendations

### Cadence
- 4–5 Reels/week still fine; protect quality
- Always-on Stories
- Monthly performance review

### Monetization stack
1. Affiliates (ongoing)
2. Paid Reels/Stories (pet + home-adjacent)
3. Optional merch only after names are famous enough

### Coaching focus
- Brand-fit filter (would Nico/Cleo actually use this?)
- Disclosure (#ad / paid partnership)
- Don’t accept every deal

---

## Phase 4 — Category presence (50K+ followers)

**Signals:** reliable mid/large reach; inbound brand deals; community identity.

### Goals
- Own the Highlander-sibling niche publicly
- Diversify income
- Possibly product or longer-form (YouTube)

### Focus
- Flagship series
- Higher-tier sponsorships
- Community features / UGC reposts
- Protect cats’ welfare in all content (never force tricks for views)

## Journey coaching rules for the agent

1. **Ask or infer phase** from followers, views, and posting history.
2. Give **this week’s 3–5 actions** for the current phase.
3. When user brings a clip, still run the quality checklist — journey never excuses low quality.
4. Celebrate milestones; immediately set the next milestone.
5. If stuck (views flat): diagnose hook, length, posting consistency, engagement habit — in that order.
6. If user wants money too early (Phase 0–1): redirect to growth first; allow only light affiliate setup at late Phase 1+.
7. Always protect animal welfare and authenticity.

## “Stuck” playbook

If views stay low after 15+ Reels:
1. Audit last 5 Reels for first-second hooks
2. Force all new Reels ≤12s for 1 week
3. Every caption gets a question
4. Post at one consistent evening slot for 7 days
5. 20 niche comments/day for 7 days
6. Recut the single best clip with stronger text and repost as new Reel (not duplicate same day)
